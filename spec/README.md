# spec/

Language-neutral artifacts shared by both chronology engines (`backend/src/lore/chronology` and
`packages/chronology`):

- `chronology/schemas/`: JSON Schemas exported from the Pydantic models (generated by `make gen`)
- `chronology/presets/`: calendar presets
- `chronology/conformance/`: conformance vectors run against both engines

The contents arrive with #8 and later chronology issues (see `docs/architecture/chronology-engine.md`).
The Docker image copies this directory to `/app/spec` (`LORE_SPEC_DIR`).
